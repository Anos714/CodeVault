Chrome extension settings

Connect your account

Create a personal access token in CodeVault, then paste it here. The token stays on this device in chrome.storage.local.

Don't have a token? Open CodeVault settings and create one under API tokens.

Local development: run bun run dev in frontend/, keep the URL at http://localhost:3000, and load this folder unpacked from chrome://extensions. Tokens grant full access to your vault — revoke one from CodeVault settings at any time.
